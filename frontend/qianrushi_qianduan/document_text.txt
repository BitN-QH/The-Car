嵌入式芯片与系统设计竞赛
项目申报书
基于 RDK X5 多模态感知与自主导航的
具身智能全向搬运机器人
摘要
针对传统叉车及自动导引车(AGV)在仓储物流场景中智能化程度不足、动态避障能力有限及远程运维不便等问题，本团队设计并实现了一套基于 RDK X5 多模态感知与自主导航的具身智能全向搬运机器人系统。系统以麦克纳姆轮底盘为移动平台，具备全向移动能力；采用“STM32 实时底层控制 + RDK X5 智能感知决策”的分层协同架构，STM32 控制器负责底盘电机驱动、叉取机构控制及传感器数据采集等实时底层任务，RDK X5 负责 SLAM 定位建图、路径规划、目标检测、任务分析及远程运维等高层智能任务，二者通过 UART 串口通信协议协同工作。
系统融合 SLAM、YOLO、Nav2 等关键技术，由 RDK X5 实现环境建图定位、目标识别、自主导航与动态避障，并通过串口向 STM32 下发底盘运动和叉取机构控制指令，实现感知与执行的分层协同。系统支持目标搜索、区域导航、场景巡检和任务级自主执行，可实现托盘搬运、到点导航、目标定位、状态监测、异常告警及远程任务下发等功能，适用于智能仓储托盘搬运、车间物料转运等场景，具有较强的自主性、实时性和工程应用价值。
一、项目背景与意义
1.1 行业背景
随着智能制造与智慧物流的快速发展，仓储物流场景对自动化搬运设备的需求日益增长。传统叉车依赖人工驾驶，存在劳动强度大、作业效率低、安全风险高等问题；而现有 AGV 虽然能够实现固定路径运输，但在复杂动态环境中普遍存在智能化程度不足、动态避障能力有限、任务理解能力弱、远程运维不便等缺陷，难以满足柔性化、智能化仓储物流的需求。
1.2 现有问题分析
传统叉车：人工操作成本高，长时间作业易疲劳，存在安全隐患，无法实现 7×24 小时连续作业。
固定路径 AGV：依赖磁条或二维码，部署周期长，路径变更困难，难以适应动态变化的仓储环境。
智能感知不足：多数搬运设备缺乏视觉目标检测能力，无法根据场景信息自主执行高层次任务。
动态避障能力弱：缺少多模态传感器融合与实时局部避障能力，难以在人机混行环境中安全运行。
运维管理不便：缺乏远程任务下发、状态监测和异常告警机制，难以实现集中化运维管理。
1.3 项目意义
本项目基于 RDK X5 开发板设计并实现具身智能全向搬运机器人，通过融合 SLAM、YOLO、Nav2 等前沿技术，构建具备环境感知、自主导航、动态避障和任务级执行能力的智能搬运系统。该作品不仅能够提升仓储物流作业的自动化与智能化水平，还可为智能制造、智慧物流等应用场景提供可落地的技术方案，具有重要的工程应用价值与社会经济效益。
二、项目目标
2.1 总体目标
设计并实现一套基于 RDK X5 的具身智能全向搬运机器人系统，使其能够在仓储物流场景中自主完成环境建图、定位导航、目标识别、托盘搬运、动态避障和远程任务执行等任务。
2.2 具体目标
构建基于麦克纳姆轮的全向移动底盘，实现前、后、左、右、斜向及原地旋转等全向运动能力。
基于 RDK X5 实现 SLAM 建图与实时定位，支持大面积仓储环境的高精度地图构建。
融合激光雷达、RGB-D 相机等多模态传感器，实现动态障碍物检测与局部避障。
基于 YOLO 实现托盘、货物、人员等目标的实时检测与定位。
基于 Nav2 实现全局路径规划、局部路径规划与自主导航。
开发远程运维平台，支持任务下发、状态监测、异常告警和日志管理。
实现托盘搬运、到点导航、目标搜索、场景巡检等典型应用场景演示。
三、系统总体架构
3.1 架构设计
系统采用“STM32 实时底层控制 + RDK X5 智能感知决策”的分层协同架构。STM32 微控制器部署于机器人本体底层，负责麦克纳姆轮电机驱动、叉取机构控制、编码器读取及 IMU 等传感器数据采集等实时控制任务；RDK X5 作为上位机负责 SLAM 定位建图、Nav2 路径规划、YOLO 目标检测、局部避障、任务规划和远程运维等高层智能任务。RDK X5 与 STM32 之间通过 UART 串口通信，RDK X5 向 STM32 下发底盘速度指令和叉取机构控制指令，STM32 向 RDK X5 上报里程计、IMU 数据和执行机构状态，实现感知与执行的分层解耦。

3.3 技术路线图
第一阶段：硬件平台搭建，包括底盘装配、传感器集成和 RDK X5 环境部署。
第二阶段：SLAM 建图与定位，实现环境地图构建和实时位姿估计。

第四阶段：导航与避障，基于 Nav2 实现路径规划、动态避障和自主移动。
第五阶段：任务级执行与远程运维，集成搬运、巡检、搜索等功能并开发远程管理端。

4.2 分层控制架构
系统采用双层控制器架构。RDK X5 作为上位机，运行 Ubuntu 与 ROS2，负责 SLAM 建图、Nav2 导航规划、YOLO 目标检测等计算密集型任务，生成底盘速度指令和叉取机构控制指令后通过 UART 串口发送给 STM32。STM32 作为下位机，负责解析串口指令，驱动四个麦克纳姆轮电机和叉取机构电机，读取编码器和 IMU 数据，并将里程计和传感器状态通过串口上报给 RDK X5，为 SLAM 和导航提供 odom 话题数据。
4.3 全向移动底盘设计
采用麦克纳姆轮全向移动底盘，由 STM32 驱动四路电机，通过四个轮子的独立速度合成，实现机器人前进、后退、横移、斜向移动和原地旋转。相比传统差速底盘，全向底盘具有更高的机动性和空间利用率，更适合仓储物流中狭窄通道和紧凑转弯场景。
4.4 传感器布局
激光雷达和 RGB-D 相机直接接入 RDK X5，用于 SLAM 建图、障碍物检测和目标识别；IMU 和编码器接入 STM32，用于底层运动控制和里程计计算。STM32 将融合后的里程计数据通过串口上报 RDK X5，为 Nav2 导航提供定位输入。多传感器数据在 RDK X5 端通过 ROS2 话题进行时间同步和融合。
五、软件设计
5.1 软件架构
软件系统分为 RDK X5 上位机软件和 STM32 下位机固件两部分。RDK X5 上基于 ROS2 框架构建模块化节点，包括 SLAM 节点、Nav2 导航节点、目标检测节点、避障节点、任务执行节点和远程运维节点；底层串口通信节点负责与 STM32 进行指令下发和状态上报。STM32 固件基于 FreeRTOS 或裸机开发，包括串口协议解析、电机 PID 控制、叉取机构控制、编码器读取和 IMU 数据融合模块。
5.2 开发环境
RDK X5 操作系统：Ubuntu 22.04 LTS + ROS2 Humble
STM32 开发环境：STM32CubeIDE + HAL 库 / FreeRTOS
编程语言：Python 3 / C++ (RDK X5)，C (STM32)
AI 框架：PyTorch / ONNX Runtime / ROS2 推理节点
仿真工具：Gazebo / RViz2
5.3 串口通信协议
RDK X5 与 STM32 之间通过 UART 串口通信，采用自定义二进制协议。RDK X5 向 STM32 发送底盘速度指令（线速度 vx、vy 和角速度 wz）和叉取机构控制指令（升降高度、动作指令）；STM32 向 RDK X5 上报里程计数据（累计位移和航向角）、IMU 姿态数据及执行机构状态。ROS2 端通过串口通信节点将串口数据转换为 odom 和 cmd_vel 话题，实现与 Nav2 的无缝对接。

六、关键技术
6.1 SLAM 建图与定位
采用激光 SLAM 或视觉-激光融合 SLAM 算法，在 RDK X5 上实现实时环境建图与定位。通过 IMU 数据进行运动畸变补偿，结合回环检测提高地图一致性和定位精度。输出占据栅格地图和机器人实时位姿，为 Nav2 导航提供基础。
6.2 YOLO 目标检测
针对仓储物流场景，基于 YOLO 系列模型训练托盘、货物、人员、货架等目标检测模型。通过 RGB-D 相机获取目标深度信息，估计目标在机器人坐标系中的 3D 位置，为托盘叉取和导航目标点计算提供依据。
6.3 Nav2 自主导航
基于 ROS2 Nav2 框架实现自主导航。全局路径规划器根据地图规划最优路径；局部路径规划器结合实时感知数据动态避障；行为树控制器管理导航状态和恢复行为，确保机器人在动态环境中安全高效地到达目的地。
6.4 多模态感知融合
融合激光雷达、RGB-D 相机和 IMU 数据，构建统一的环境感知表示。激光雷达提供远距离障碍物信息，相机提供目标检测和深度信息，IMU 提供运动姿态信息。通过时间同步和坐标变换，实现可靠的环境感知和动态避障。
七、功能实现
7.1 托盘搬运
机器人通过 YOLO 检测托盘位置和姿态，移动到托盘正前方，通过视觉伺服调整位姿，控制叉取机构插入托盘并升降，然后导航至目标卸货点完成卸货。
7.2 到点导航
基于 Nav2 实现目标点导航。用户可通过地图点击或坐标输入目标位置，机器人自动规划路径并行驶到目标点。
7.3 目标搜索
当用户需要寻找特定目标时，机器人基于 YOLO 目标检测在指定区域内进行巡逻搜索，发现目标后报告位置并可执行搬运任务。
7.4 场景巡检
机器人按照预设巡检路线或动态规划路径，在仓库内进行周期性巡检，检测异常状态（如货物倒塌、人员入侵、设备异常），并上报远程运维平台。
7.5 状态监测与异常告警
实时监测机器人电量、速度、位置、传感器状态和执行机构状态。当检测到电量不足、障碍物过近、任务失败等异常时，通过声光告警和远程消息通知运维人员。
7.6 远程任务下发
开发基于 Web 或移动端的远程运维平台，支持地图显示、任务编辑、实时视频回传、状态监控和远程任务下发。运维人员可随时随地控制机器人执行任务。
八、创新点
全向移动 + 具身智能：将麦克纳姆轮全向底盘与多模态感知、YOLO 目标检测相结合，提升机器人在仓储物流场景中的机动性和目标识别能力。
分层协同架构：采用 STM32 底层实时控制 + RDK X5 高层智能决策的分层架构，STM32 保障电机和叉取机构的实时性，RDK X5 专注 AI 推理与导航规划，通过串口通信实现感知与执行的解耦。
视觉驱动的自主搬运：基于 YOLO 实现托盘和货物的自动检测与定位，配合视觉伺服完成自主叉取和搬运，减少人工干预。
动态避障与安全：融合多模态传感器和 Nav2 局部规划，实现人机混行场景下的动态避障，并通过安全监测机制保障运行安全。
远程运维一体化：构建远程运维平台，实现任务下发、状态监测、异常告警和日志管理，降低部署和运维成本。
九、应用场景
智能仓储托盘搬运：在仓库、配送中心实现托盘货物的自动搬运、入库、出库和移库作业。
车间物料转运：在制造车间完成原材料、半成品和成品的工位间转运，支持柔性生产。
无人值守巡检：在仓库、机房、展厅等场所进行定时巡检，检测异常并上报。
智能分拣辅助：配合分拣系统，根据订单信息将货物搬运至指定分拣口或打包区。
展览与服务导览：在博物馆、展览馆等场景提供导览、讲解和物品搬运服务。
